= Toggle

Represents a toggleable state with associated values.

`Toggle` alternates between two states on every read, optionally returning a pair of associated values instead of a plain boolean. It suits alternating table row classes, flip-flopping labels, zebra striping and any routine that needs to switch between two outcomes.

* Namespace: `Inane\Stdlib\Control`
* File: `lib/inanepain/stdlib/src/Control/Toggle.php`

IMPORTANT: Reading `$nextState`, `$nextValue` or `$next` (and invoking the object) changes the state. Use `$state` and `$value` to inspect the current state without altering it.

== Construction

.Signature
[source,php]
----
public function __construct(
    bool $initialState = true,
    bool $useValue = false,
    null|bool|string|int|float|object $on = true,
    null|bool|string|int|float|object $off = false,
)
----

.Parameters
[cols="1,1,3"]
|===
|Parameter |Type |Description

|`$initialState`
|`bool`
|The state returned by the first toggle.

|`$useValue`
|`bool`
|When `true`, `$next` and `__invoke()` return the associated values rather than the boolean state.

|`$on`
|`null\|bool\|string\|int\|float\|object`
|The value used while the state is on.

|`$off`
|`null\|bool\|string\|int\|float\|object`
|The value that is used when the state is off.
|===

.Throws: `InvalidArgumentException` — When invalid types are supplied for `$on` or `$off`.

NOTE: The state is stored inverted on construction so that the first toggle yields `$initialState`. Consequently `$state` and `$value` report the opposite of `$initialState` until the first toggle.

.Example
[source,php]
----
use Inane\Stdlib\Control\Toggle;

$boolean = new Toggle();                                         // boolean toggle starts on
$classes = new Toggle(true, true, 'row-odd', 'row-even');        // value toggle
----

== Properties

[cols="1,1,1,3"]
|===
|Property |Type |Access |Description

|`$state`
|`bool`
|read-only
|The current state, unchanged by reading.

|`$value`
|`null\|bool\|string\|int\|float\|object`
|read-only
|`$on` or `$off` for the current state, unchanged by reading.

|`$nextState`
|`bool`
|read-only
|Toggles the state and returns the new boolean state.

|`$nextValue`
|`null\|bool\|string\|int\|float\|object`
|read-only
|Toggles the state and returns the matching value.

|`$next`
|`null\|bool\|string\|int\|float\|object`
|read-only
|Toggles the state and returns either the value or the boolean state, according to `$useValue`.
|===

== Methods

=== __invoke

Invokes the toggle logic, making the object callable.

.Signature
[source,php]
----
public function __invoke(?bool $getValue = null): null|bool|string|int|float|object
----

.Parameters
[cols="1,1,3"]
|===
|Parameter |Type |Description

|`$getValue`
|`bool\|null`
|Mode selector: `true` returns the associated value, `false` returns the boolean state, and `null` (default) follows the `$useValue` flag set on construction.
|===

.Returns: `null\|bool\|string\|int\|float\|object` — The new state or its associated value.

.Example
[source,php]
----
$toggle = new Toggle(true, false, 'on', 'off');

$toggle();       // true   (follows $useValue)
$toggle(true);   // 'off'  (value mode)
$toggle(false);  // true   (boolean mode)
----

== Usage

.Alternating row classes
[source,php]
----
use Inane\Stdlib\Control\Toggle;

$row = new Toggle(true, true, 'odd', 'even');

foreach ($items as $item) {
    echo "<tr class=\"{$row->next}\">...</tr>";
}
----

.Boolean flip-flop
[source,php]
----
$flag = new Toggle();

$flag->nextState;  // true
$flag->nextState;  // false
$flag->state;      // false, reading doesn't toggle
----

.Starting off
[source,php]
----
$toggle = new Toggle(false, true, 'on', 'off');

$toggle->value;      // 'on', the inverted initial state
$toggle->nextValue;  // 'off', the first toggle
$toggle->nextValue;  // 'on'
----
