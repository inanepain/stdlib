= StepLimiter

Step class for tracking progress towards a limit.

`StepLimiter` counts how many times it’s been asked to continue and reports whether the configured limit has been reached. It suits retry loops, paged batches, throttled iterations and any routine that should run a fixed number of times.

* Namespace: `Inane\Stdlib\Control`
* File: `lib/inanepain/stdlib/src/Control/StepLimiter.php`

IMPORTANT: Reading `$canContinue` (or invoking the object) consumes a step; the internal counter is incremented on every read. Use `$current` and `$remaining` when you only need to inspect progress.

== Construction

.Signature
[source,php]
----
public function __construct(int $limit = 1)
----

.Parameters
[cols="1,1,3"]
|===
|Parameter |Type |Description

|`$limit`
|`int`
|Target number of steps. Negative values are clamped to `0`.
|===

.Example
[source,php]
----
use Inane\Stdlib\Control\StepLimiter;

$limiter = new StepLimiter(3);   // three steps allowed
$single  = new StepLimiter();    // default limit of one
$none    = new StepLimiter(-5);  // clamped to zero, never continues
----

TIP: The static factory `StepLimiter::withLimit()` offers the same construction in a fluent form.

== Properties

[cols="1,1,1,3"]
|===
|Property |Type |Access |Description

|`$limit`
|`int`
|read-only
|The target limit is set on construction.

|`$current`
|`int`
|read-only
|Number of steps consumed so far.

|`$remaining`
|`int`
|read-only
|Steps left before the limit is reached, never less than `0`.

|`$canContinue`
|`bool`
|read-only
|Consumes a step and returns `false` once the limit is exceeded.
|===

NOTE: `$current` may exceed `$limit` when `$canContinue` is read after the limit has been reached; `$remaining` stays at `0`.

== Methods

=== withLimit

Creates a new instance with the specified limit, a static alternative to the constructor that reads well when chaining.

.Signature
[source,php]
----
public static function withLimit(int $limit = 1): self
----

.Parameters
[cols="1,1,3"]
|===
|Parameter |Type |Description

|`$limit`
|`int`
|Target number of steps. Negative values are clamped to `0`.
|===

.Returns: `self` — A new `StepLimiter` configured with the given limit.

.Example
[source,php]
----
use Inane\Stdlib\Control\StepLimiter;

$limiter = StepLimiter::withLimit(3);  // three steps allowed
$single  = StepLimiter::withLimit();   // default limit of one
$none    = StepLimiter::withLimit(-5); // clamped to zero, never continues
----

NOTE: `withLimit()` is equivalent to `new StepLimiter($limit)`; pick whichever reads better at the call site.

=== __invoke

Invokes the canContinue check, making the object callable.

.Signature
[source,php]
----
public function __invoke(): bool
----

.Returns: `bool` — `true` while steps remain; `false` once the limit is exceeded.

.Example
[source,php]
----
$limiter = new StepLimiter(2);

$limiter();  // true
$limiter();  // true
$limiter();  // false
----

== Usage

.Limiting a loop
[source,php]
----
use Inane\Stdlib\Control\StepLimiter;

$limiter = new StepLimiter(3);

while ($limiter->canContinue) {
    // executes three times
    process();
}
----

.Limiting retries
[source,php]
----
$attempts = new StepLimiter(5);

do {
    $result = fetch();
} while ($result === null && $attempts());

if ($result === null) {
    // five attempts exhausted
}
----

.Inspecting progress
[source,php]
----
$limiter = new StepLimiter(3);

$limiter->canContinue;  // true
$limiter->current;      // 1
$limiter->remaining;    // 2
$limiter->limit;        // 3
----
